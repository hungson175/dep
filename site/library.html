One import. One decision.

Export your own DEEPSEEK_API_KEY in your launching environment. Keep it out of source code. The library never reads .env files or contacts a model when imported.

from dep_deepseek import DeepSeek

dep = DeepSeek()
answer = dep.choice(
    "Please cancel my order.",
    "What does the customer want?",
    {"cancel": "Cancel an order",
     "track": "Track a shipment",
     "other": "Anything else"},
)

print(answer["choice"])
print(answer["probabilities"])

The probability map includes every option you supplied. Values sum to one. Choice ties use the first supplied option.

Three question types.

MethodWhat you get
choiceA supplied label and probabilities over all options.
noulProbability of true; a complete true/false map.
scoreExpected 1-based level; a complete level map and legend.
urgent = dep.noul("Help me now!", "Is this urgent?")
mood = dep.score("I am frustrated.", "How upset?",
                 ["calm", "annoyed", "angry"])

result = dep.predict(
    {"message": "My payment failed. Help!"},
    {
        "urgent": {"type": "noul", "instructions": "Is this urgent?"},
        "route": {"type": "choice", "instructions": "Which team?",
                  "criteria": ["payments", "sales", "other"]},
    },
)
print(result["answers"])
print(result["usage"])

predict(state, questions) makes one serial request per question, validating the whole batch before sending anything. Every answer includes confidence: the top probability minus the runner-up.

Missing means 0% by default.

When DeepSeek omits an option from its first-token top-20 report, the library returns 0.0 for that option and normalizes the available candidates. Check answer["diagnostics"]["missing_options"] when you need visibility into the fallback.

Zero-fill is an approximation for unreported probability, not proof that the model assigned exactly zero. It can inflate confidence. These probabilities are not empirically calibrated.

If every candidate is absent, or the report is malformed, the library raises DistributionError. To reject any missing option instead:

strict = DeepSeek(missing_policy="error")

Know what you’re running.

This is a hosted inference adapter, not a fine-tuned model. It uses deepseek-flash (DeepSeek V4.1 Flash), thinking disabled, one output token, temperature 1, and top-20 logprobs. There is no logit bias or free-text parsing fallback.

Installed library calls use your own DeepSeek account and key; provider charges apply. The playground offers a separate, shared DeepSeek demo with a $20 lifetime cap; Bonsai remains its default. The library itself has no automatic retries, cache, or spending cap. A later batch failure can still leave completed calls billed.

Catch APIError for HTTP failures, TransportError for network failures, and DistributionError for unusable reports. Invalid inputs raise ValueError or serialization errors.

Text or JSON-serializable state is supported; choice accepts a mapping or unique label list; score accepts an ordered list. Up to 35 options are supported. Outputs do not establish correct decisions or prompt-injection resistance; do not use this as the sole high-stakes control.
